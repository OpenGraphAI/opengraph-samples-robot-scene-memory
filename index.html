Explore recurring objects across robot-camera observations.

The gallery shows a fixed 127-node graph snapshot generated offline with opengraph-image. Cytoscape.js provides read-only zooming, panning, filtering, and inspection in the browser.

02 · Install MCP

Grow a graph through conversation.

The gallery is a static snapshot. The local MCP server lets a compatible client build and query newer graph snapshots from your own images. Install uv, replace the key placeholder locally, then restart your client.

Claude Desktop

claude_desktop_config.json

{
  "mcpServers": {
    "opengraph-image": {
      "command": "uvx",
      "args": [
        "--from",
        "opengraph-image==0.1.2",
        "opengraph-image-mcp"
      ],
      "env": {
        "ANTHROPIC_API_KEY": "YOUR_ANTHROPIC_API_KEY"
      }
    }
  }
}

Windows: %APPDATA%\Claude\claude_desktop_config.json. Fully quit and reopen Claude Desktop after saving.

Cursor

.cursor/mcp.json

{
  "mcpServers": {
    "opengraph-image": {
      "command": "uvx",
      "args": [
        "--from",
        "opengraph-image==0.1.2",
        "opengraph-image-mcp"
      ],
      "env": {
        "ANTHROPIC_API_KEY": "YOUR_ANTHROPIC_API_KEY"
      }
    }
  }
}

Save as .cursor/mcp.json in a trusted project, then enable the server in Cursor’s MCP settings.

The key is required only when the MCP server extracts or queries a graph with Claude. Viewing this gallery never uses it. If the client cannot find uvx, replace it with the absolute path returned by where uvx on Windows or which uvx on macOS/Linux.
