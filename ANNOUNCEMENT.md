## LinkedIn

Robot Scene Memory, the first OpenGraph AI sample gallery, is now live.

We used `opengraph-image` to organize eight attributed BridgeData V2 robot-camera observations into a 65-node, 148-relationship scene memory. The result is published as a static, read-only D3.js gallery: visitors can search, filter, zoom, and inspect the graph without an account, backend, or API key.

This is a scene-memory example—not a training pipeline. The repository includes the selected source observations, exact attribution and checksums, the generated graph, and reproducible build instructions.

- Demo: https://opengraphai.github.io/opengraph-samples-robot-scene-memory/
- Source: https://github.com/OpenGraphAI/opengraph-samples-robot-scene-memory
