# Contributing

Contributions that improve the scene-memory example, its documentation, or its accessibility are welcome.

An example contribution should include:

- Redistributable source data with clear attribution and license information
- The generated `graph.json`
- A short README explaining what the example shows, how it was produced, and what to notice in the graph

Keep generated outputs reproducible, remove sensitive information, and never commit API keys or `.env` files. Open an issue before proposing a different dataset or changing the example's scope.
